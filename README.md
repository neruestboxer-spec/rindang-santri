# Rindang Santri

Aplikasi web pencatatan dan peringkat hafalan surah pendek Juz 30.

- **Frontend:** HTML/CSS/JS vanilla (folder ini), di-hosting di GitHub Pages.
- **Backend:** Google Apps Script (`Kode.gs`, tidak disimpan di repository ini) sebagai REST API JSON, dengan Google Sheets dan Drive.

Sebelum dipakai, isi `GAS_URL` di `js/config.js` dengan URL Web App Apps Script yang berakhiran `/exec`.
Langkah lengkapnya ada di `PANDUAN-INSTALASI.md`.
